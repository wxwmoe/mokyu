# 管理指南

Mokyu 面向应用媒体存储。单管理员可直接管理所有桶；有多个项目时，再启用成员和权限。文件仍通过 S3 接入，管理页面补充浏览、维护和授权。

## 第一次使用

1. 按[部署说明](deployment-and-recovery.md) 启动服务，打开管理端口。
2. 用 `docker exec mokyu cat /run/mokyu/setup-token` 取得一次性初始化令牌，在页面创建管理员；也可执行 `docker exec -it mokyu cli user create admin`。
3. 在“存储桶设置”创建桶，在“应用密钥”签发此桶的 S3 凭据，保存只显示一次的 secret。
4. 将 endpoint、region、桶名和密钥填入应用。默认对象私有；需要公开媒体时，由应用设置 public-read，或在媒体库显式调整 ACL。

“工作空间”放日常媒体、传输、空间洞察和整理入口；“管理”放桶设置、用户、应用密钥、后台任务、审计和服务状态。管理员始终能查看全部桶与文件，不需要切换成某个成员。

## 媒体库

打开桶后，可按目录浏览，或按名称/路径、类型、大小、更新时间和公开状态检索。排序和筛选保存在 URL。名称包含搜索依赖后台目录索引；索引构建期间仍能浏览目录、按路径前缀或完整路径查找。

- **列表 / 图库**：图库按需请求缩略图；不支持的格式保留类型图标，不自动加载大原图。
- **快速查看**：预览、文件身份和下载保持可见，详细信息按信息/访问/存储分栏。展开后可宽幅看图，左右箭头切换对象；音视频由用户明确加载。
- **批量操作**：选择当前页，可复制、移动、改 ACL 或删除；文件菜单还能重命名和编辑元数据。逐项显示成功与失败，不把部分成功当作整批成功。
- **版本保护**：确认期间对象已变化时，操作拒绝替换新版本。响应丢失可在当前操作窗口重试；关闭浏览器不保留该窗口的操作编号。
- **公开链接**：桶设置中的公共 URL 只生成 public-read 文件链接；私有下载使用受授权的管理接口，不产生永久分享链接。

HTML/SVG 不嵌入管理页面，文本以转义内容显示；下载按原始字节返回。缩略图是可丢弃衍生数据，不改变原文件。

## 上传与传输

媒体库可选择文件上传；传输中心查看正在接收、已发布但待后端落盘、已存后端以及失败项。可暂停本标签页发送、终止上传，或重新选择原文件续传；续传会核对已接收分片的校验和。

页面不把整文件读进内存，也不向浏览器签发 S3 secret。刷新后不能自动继续读取本地文件，需要用户重新选择。成员只能续传自己发起的 Web 上传，管理员可以查看和终止其他上传。

**“上传完成”与“后端已保存”是不同状态。** 上传缓存开启时，成功响应可能依赖本地受保护文件。备份前应排空，或一致备份数据库和这些文件，见[恢复要求](deployment-and-recovery.md#备份材料)。

## 项目、用户和权限

默认项目管理关闭，全部数据归内置 Default 项目；单管理员不必建立组织结构。创建额外项目或普通用户时才启用项目管理。

推荐流程：管理员创建项目 → 建桶或转入已有桶 → 创建成员 → 选择项目角色及全部/指定桶范围 → 按需签发应用密钥或个人 Token。

| 身份 | 可做什么 |
| --- | --- |
| 实例管理员 | 所有桶、对象、用户、授权、全局统计和维护 |
| reader | 授权桶的目录、下载、区块和空间洞察 |
| writer | reader + 上传、删除、ACL |
| maintainer | writer + CORS、网站设置 |

指定桶授权还可以缩减动作，例如只列举、只读或只写。普通用户默认不能创建桶；项目开启“允许创建桶”后，具备 maintainer 角色的成员可以创建，仍受项目桶数及容量限制。成员看到自己范围的去重、共享内容和编码节省，不暴露未授权桶的文件或完整共享包信息。

成员角色不是实例管理员，不能管理其他用户、后端密钥或全局维护。用户禁用/删除不删除项目媒体和 S3 应用密钥；最后一个启用的管理员有保护。强制改密的用户须先修改密码才能访问业务页面。

### 应用密钥与个人 Token

| 类型 | 使用方式 | 权限和生命周期 |
| --- | --- | --- |
| S3 应用密钥 | access key + secret key，供应用或 S3 SDK | 属于项目，逐桶授权；独立于创建者账号，可禁用、轮换和设到期 |
| 个人 API Token | `Authorization: Bearer ...`，调用管理 API | 与用户当前权限取交集；改密、禁用或角色变化使旧 Token 失效 |
| system Token | 管理员显式选择 | 全实例自动化，不能调用 Cookie 专属账户入口 |

secret 只显示一次，列表不会重新展示。轮换应用密钥可设置旧密钥重叠期；撤销或缩减权限会阻止尚未发布的写入。个人 Token 的创建和管理通过个人菜单进入。

## 容量与空间洞察

项目可限制逻辑容量、在途上传量和桶数；桶可独立限制逻辑容量。空上限表示不限，0 表示不允许新增该项用量。按原始对象大小计入额度，去重/压缩不抵扣；降低额度不删现有文件。

概览与存储空间页面依次解释：原始媒体量 → 范围内唯一内容 → 跨项目/桶分摊的内容 → 编码后的存储份额。共享内容不能按桶简单相加，编码节省也可能为负；这不是后端供应商账单。

管理员另可查看独立区块、区块包、过渡副本、待回收、区块缓存及其内部上传缓存。统计由后台采集，显示实际时间；首次收集中、过期快照和待上传的未知编码量会明确标示，刷新页面不扫描全库存。

## 整理、巡检与恢复

“整理工作台”控制执行策略，“后台任务”查看每次运行的状态、进度和历史。任务颜色跟随类型，状态另用标记区分。定时任务由服务执行，无需 crontab。

| 控制 | 用途 |
| --- | --- |
| 打包 / 复用拆分 / 无引用成员整理 / 碎片合并 / Range 优化 | 暂停、恢复对应策略，或立即执行一次 |
| 区块回收 / 历史清理 | 分开控制远端空间与数据库历史 |
| 停止新包生成 | 覆盖上传及所有维护生产路径，准备全部拆包 |
| 单包 / 全部拆包 | 预览影响后确认，先写新来源再切换引用 |
| 上传缓存落盘 | 将已有积压写入后端；备份前先停止新写入并排空活跃操作 |
| 完整性巡检 | metadata/head/full 三种深度，查看异常与关联文件，下载完整 JSONL 报告 |
| 后端清查 | 先只读扫描，确认后删除数据库未索引的规范路径；仅恢复或管理需要时使用 |
| 维护模式 | 阻止新写入、远端 GC 及改写任务；已接纳请求须另等排空 |

暂停是工作边界处暂停，不是回滚当前批次。拆包、清桶和清查有影响预览、明确名称/范围确认及近期密码验证；任务入队不等于完成。全部拆包前需停止生成新包并等待准备中的包收尾，未完成的全部拆包会阻止重新开启生成。

破坏性后端清查需要维护模式、排空操作及非空索引，每次删除前仍检查引用。巡检只报告、不自动修复。配置编辑、密钥文件安装、数据库备份恢复仍在部署环境完成；Web 服务状态可查看脱敏运行配置并生成新的随机密钥材料。

## 个人偏好与交互

English / 简体中文 / 日本語按需加载。未登录使用浏览器已保存的选择，其次匹配浏览器优先语言，最后回退英语；登录后以用户设置为准，同时同步本地选择。

顶栏快速切换亮色/暗色，个人设置可选自动。头像默认关闭；启用后请求配置的 Gravatar 或兼容镜像，浏览器会向该服务发送邮箱哈希。改密、当前会话和其他会话撤销也在个人设置。

菜单、选框、日历、确认框均为统一的可键盘操作组件；支持焦点返回、小屏导航和减少动画偏好。身份跨标签页变化会清理旧页面和上传句柄。错误附 Request ID，反馈问题时可连同服务日志定位。
